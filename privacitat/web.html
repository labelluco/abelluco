Estadístiques de visites

Per saber quantes persones visiten la web i quines pàgines interessen, faig servir GoatCounter. No fa servir galetes, no desa la teva adreça IP i no et segueix d'una web a una altra. Només guarda dades agregades: la pàgina visitada, d'on vens, el navegador i el sistema, la mida de la pantalla, l'idioma i el país (deduït de la IP, que després es descarta). Les dades es guarden a servidors de la Unió Europea.

Què es desa al teu navegador

La web s'allotja a GitHub Pages. Com qualsevol servidor, GitHub rep la teva adreça IP quan obres una pàgina, i la tracta segons la seva pròpia política de privadesa.

Si m'escrius

Si m'escrius per correu o per WhatsApp, només faré servir el que m'expliquis per respondre't i, si cal, per preparar el que em demanis. No ho cedeixo a ningú. Pots demanar-me en qualsevol moment que ho esborri.

Els teus drets

Pots demanar accedir a les teves dades, corregir-les o esborrar-les escrivint a labellucoapps@gmail.com. Si no hi estàs d'acord, també pots reclamar a l'Agència Espanyola de Protecció de Dades (aepd.es).

Privacy on this website

Last updated: 14 November 2026

This website (labelluco.net) is made by Mario Escuder Nebot (contact: labellucoapps@gmail.com). It has no user accounts, no advertising and no cookies. Each app has its own privacy policy, linked from the apps page.

Visit statistics

To know how many people visit the website and which pages are of interest, I use GoatCounter. It uses no cookies, does not store your IP address and does not follow you from one website to another. It only keeps aggregate data: the page visited, where you came from, the browser and system, screen size, language and country (worked out from the IP, which is then discarded). The data is stored on servers in the European Union.

What is stored in your browser

Only the language you choose, so the website remembers it. It never leaves your device.

Hosting

The website is hosted on GitHub Pages. Like any server, GitHub receives your IP address when you open a page, and handles it under its own privacy policy.

If you write to me

If you write to me by email or WhatsApp, I will only use what you tell me to reply and, if needed, to prepare what you ask for. I do not pass it on to anyone. You can ask me to delete it at any time.

Your rights

You can ask to access, correct or delete your data by writing to labellucoapps@gmail.com. If you disagree, you can also complain to the Spanish Data Protection Agency (aepd.es).
